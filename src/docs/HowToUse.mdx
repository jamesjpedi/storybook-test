# How to Use

This Storybook documents the BHHC design system built on MUI Material and MUI X. Use the sidebar to browse stories. For install and import paths in a consumer app, see **Getting started**.

## Run locally

```bash
npm install
npm run storybook
```

Storybook starts at [http://localhost:6006](http://localhost:6006). Use `npm run dev` if you want the Vite demo app instead of the component explorer.

## Import a component

In this repo, import wrappers from `src/components` or the package entries under `src/exports`. In a consumer app, import from `bhhc-design-system` (see Getting started).

```tsx
import { Button, Card, CardContent, Typography } from 'bhhc-design-system';
import { DataGrid } from 'bhhc-design-system/x-data-grid-premium';

export function Example() {
  return (
    <>
      <Button variant="contained">Save changes</Button>
      <Card>
        <CardContent>
          <Typography variant="h6">Policy summary</Typography>
        </CardContent>
      </Card>
    </>
  );
}
```

## Button

Use **Button** for actions. It is MUI `Button` with BHHC theme defaults. Use `contained`, `outlined`, or `text`, then a size.

<Canvas of={ButtonStories.Contained} />
<Canvas of={ButtonStories.Outlined} />

| Prop       | Type                                  | Default               | Description         |
| ---------- | ------------------------------------- | --------------------- | ------------------- |
| `children` | `ReactNode`                           | —                     | Button label        |
| `variant`  | `'contained' \| 'outlined' \| 'text'` | `'contained'` (theme) | Visual style        |
| `size`     | `'small' \| 'medium' \| 'large'`      | `'medium'`            | Control size        |
| `disabled` | `boolean`                             | `false`               | Disables the button |
| `onClick`  | `() => void`                          | —                     | Click handler       |

All other [MUI Button](https://mui.com/material-ui/api/button/) props are supported.

## Add a new override

1. Create a folder under `src/components/YourComponent`.
2. Wrap the MUI primitive, add stories, and re-export from the matching `src/exports/` entry (named export after `export *` so it overrides).
3. Set `title: 'Components/YourComponent'` and `tags: ['autodocs']`.

## Publish a changelog version

Do not add changelog files by hand. On `qa`, a `release:<slug>` branch, or `master`:

```bash
npm run release
```

That updates `package.json`, `CHANGELOG.md`, `src/docs/changelog/versions/<version>.md`, and an annotated `v*` tag (`1.0.0-qa.1`, `1.0.0-<slug>.1`, `1.0.0`). Open **Changelog** in the sidebar to pick a version. Full rules are in `dev-docs/VERSIONING.md`.
