# How to Use

This Storybook documents UI components built with React, TypeScript, and Vite. Use the sidebar to browse stories, then copy the patterns below into your app.

## Run locally

```bash
npm install
npm run storybook
```

Storybook starts at [http://localhost:6006](http://localhost:6006). Use `npm run dev` if you want the Vite app instead of the component explorer.

## Import a component

Components are exported from `src/components`.

```tsx
import { Button, Card } from '../components';

export function Example() {
  return (
    <>
      <Button label="Save changes" onClick={() => {}} />
      <Card
        title="Policy summary"
        description="Review coverage details in one place."
      />
    </>
  );
}
```

## Button

Use **Button** for actions. Pick `primary` or `secondary`, then a size.

<Canvas of={ButtonStories.Primary} />
<Canvas of={ButtonStories.Secondary} />

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `label` | `string` | — | Visible button text |
| `variant` | `'primary' \| 'secondary'` | `'primary'` | Visual style |
| `size` | `'small' \| 'medium' \| 'large'` | `'medium'` | Control size |
| `disabled` | `boolean` | `false` | Disables the button |
| `onClick` | `() => void` | — | Click handler |

## Card

Use **Card** to group a title and short description. Add an optional `eyebrow` for status or category.

## Add a new component

1. Create a folder under `src/components/YourComponent`.
2. Add `YourComponent.tsx`, styles, and `YourComponent.stories.ts`.
3. Export it from `src/components/index.ts`.
4. Set `title: 'Components/YourComponent'` and `tags: ['autodocs']` so Storybook generates a Docs tab.

## Publish a changelog version

Changelog notes are **plain markdown files**, one file per version. There is no semantic versioning — name files however you like (`Launch.md`, `Summer-Refresh.md`, `2026-09.md`).

1. Add a file in `src/docs/changelog/versions/`.
2. Write notes in markdown.
3. Restart Storybook if the new file does not appear immediately.
4. Open **Changelog** in the sidebar and pick the version from the dropdown.

The filename (without `.md`) is the label in the dropdown. Files are listed newest-first using the filename, so a `YYYY-MM` prefix keeps them in date order.
