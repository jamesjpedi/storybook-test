# Changelog

Pick a package version to load its notes. Each file in `src/docs/changelog/versions/` is generated by `npm run release` and named after the SemVer tag (`1.0.0-development.1`, `1.0.0-qa.1`, `1.0.0`). Versioning rules are in `dev-docs/VERSIONING.md`.
